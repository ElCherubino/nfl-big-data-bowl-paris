# Agent presentation checklist (quick version)

**Only create an actual competition presentation after kickoff and when permitted.**

- [ ] One primary stakeholder and decision
- [ ] Exactly one defensible discovery claim
- [ ] KPI defined with units, timeframe, denominator and sample size
- [ ] Baseline comparison and known existing NFL analytics checked
- [ ] Algorithm and test evidence (not just a GenAI call)
- [ ] One memorable *verified* replay/plot
- [ ] Clear business/football impact and next user action
- [ ] Disclose limitations; no unsupported causation
- [ ] Demonstrate a working result / code / reproduction
- [ ] Follow official judging instructions and deadline; no unapproved prebuilt assets

**Amazon-inspired principles:** start with customer, simplify, dive deep, earn trust, deliver results. Source: https://www.aboutamazon.com/about-us/leadership-principles
